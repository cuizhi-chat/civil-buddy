# 工作台优化 · 2026-09-18（断流 / 任务切换 / 上传下载 / 手机）

范围：Python 工作台 `demo/`、共用前端 `demo/static/`、`packing_assistant/runtime/threads.py`、装箱网关取消与导出、Rust 工作台最小改动。
起因见上一轮验收：两套后端各缺一半路由；"流式"是整轮跑完再切片；中途超时把已落盘文件从 UI 上丢掉；手机进不了门（`127.0.0.1` 硬绑 + `crypto.randomUUID` 非安全上下文）。

## 改了什么

### 断流

| 项 | 之前 | 现在 | 位置 |
|---|---|---|---|
| 流式 | 每步阻塞 `chat()`，最后按 40 字假切片 | `stream_chat()` 逐 token 推送，同时拼装 tool-call delta | `demo/llm.py`、`demo/agent.py::run_expert` |
| 心跳 | 无；模型沉默 >60 s 即被代理/手机网络切断 | `: ping` 每 `CIVIL_SSE_PING_SEC` s（默认 15） | `demo/app.py::chat` |
| 文件 | 只在 `done` 里出现；`done` 不到 = 文件丢 | 落盘即发 `file` 事件；`error` 带 `partial_text/deliverables/citations` | `demo/agent.py` |
| 前端错误 | 用错误文本覆盖已显示正文；history 留下悬空 user | 正文保留 + 状态行；`.interrupted` 标记；history 补 assistant 占位 | `demo/static/app.js` |
| 停止 | 无 | `AbortController` + 停止按钮 + `/stop`；服务端 `should_stop` 在下一 chunk 关闭上游 | `app.js`、`demo/llm.py` |
| 断连 | 同步生成器悬挂，上游继续算 | 响应结束/客户端断开 → `stop.set()` → `LLMStopped` | `demo/app.py` |
| 空 draft.md | 参数 JSON 截断 → 静默写空文件 | 拒绝写空正文，回告模型重发 | `demo/agent.py::execute_tool` |
| 超时 | 单一 120 s | connect/read/write 分开，`CIVIL_LLM_READ_TIMEOUT` 默认 180 | `demo/llm.py` |
| 并发 | 每个对话占默认线程池 | 独立 `_CHAT_POOL`（`CIVIL_MAX_CHATS`），health 等不被拖死 | `demo/app.py` |

### 任务切换

- `/api/chat` 绑定 `thread_id`（没有就新建，`context` 事件回传）；转写按行落 `demo/out/_threads/<id>.messages.jsonl`。
- 新接口：`GET /api/threads/{id}/messages`、`GET /api/threads/{id}/files`、`POST /api/threads/{id}/cancel`、`DELETE /api/threads/{id}`。
- 前端：切线程加载转写+文件+附件并重建 `history`；「新建」清屏；「并行」任务 3 s 轮询，完成后提示；`localStorage` 记住当前线程，刷新恢复；服务端换了 thread_id 时前端跟随。
- `threads.py`：原子写（tmp+rename）；重启后残留 `running` 判 `stale`；`request_cancel/cancel_requested` 协作式取消。
- 历史里连续 user 消息服务端合并。

### 上传 / 下载

- 新 `demo/attach.py`：与 Rust `attach.rs` 同目录布局、同限额（20 MB、12 个、200k 字），docx/xlsx/pdf 抽字（pdf 走 `pypdf`，扫描件明确报错）。
- `POST /api/upload`、`GET /api/attachments`、`POST /api/local`；`ChatIn.attachments` 注入提示词；`read_attachment` 工具。
- 前端 XHR 上传带进度，支持粘贴；下载链接带 `download` 属性，.md/.txt 有「预览」。
- Python `/api/file`：`filename*=utf-8''`、`inline=1`、相对路径；Rust `file_get` 同样改为 RFC 5987 + inline + 相对路径。

### 手机 / 接口对齐

- `uid()` 特性检测（`crypto.randomUUID` 只在安全上下文存在）。
- `/api/health.capabilities`（Python 与 Rust 都返回）；前端按能力隐藏按钮，不再把 404 打进对话。
- CSS：≤1100 px 右栏抽屉，≤720 px 左栏抽屉，`100dvh`、安全区、textarea 16 px 防 iOS 缩放，本机路径行隐藏，工作室单列。
- `CIVIL_HOST`：Rust `main.rs` 读环境变量；Python `demo/serve.py` 读 `.env`。非回环地址启动时打印警告（无鉴权）。
- `packing_assistant/__init__.py` 惰性导入，`demo/requirements.txt` 补齐 —— 按 demo/README 装完能直接起。

### 装箱侧

- `packing_assistant/runtime/cancel.py` 登记表；`teams/big_team.run_one` 在每个 agent 边界检查 run_id/session_id，命中则后续 agent 标 `cancelled` 跳过；新一轮运行先清登记。`POST /api/runs/{id}/cancel` 接受 run_id 或 session_id；`/api/confirm cancel` 也登记。
- `POST /api/export/shipment` 返回 `download_url`；新增 `GET /api/export/file?name=`（限 `<PACKING_OUTPUT_DIR>/exports`）。
- 前端：Vue 本地化 `frontend/vendor/vue-2.7.16.min.js`（CDN 兜底）；WS 指数退避重连；「导出 xlsx」按钮；取消/强制解锁真正取消后台运行。

## 还没做

1. Rust 端仍无 `/api/threads`、`/api/config`（前端按 capabilities 隐藏）；Rust 改动未在本机编译，需 `cargo build` 验证。
2. 装箱 pipeline 的取消只在 agent 边界生效，单个 agent 内部（如 bin3d 长算）不可中断。
3. `understand` 关键词分类器未动；召唤专家提问已改为模型基于 KB 片段作答。
4. 没有真机浏览器 e2e；建议按下面清单手测。
5. 工作台一旦 `CIVIL_HOST=0.0.0.0`，`/api/local`、`/api/config`、知识库编辑都无鉴权——上公网前必须加 token 或反代鉴权。
